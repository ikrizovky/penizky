# Penízky

Jednoduchá aplikace na správu osobních financí: kolik můžeš v tomto měsíci ještě utratit, rozpočty, import výpisů z banky (CSV, Excel), rozdělené platby, dluhy, investice a spořicí cíle.

- Funguje v prohlížeči a jde nainstalovat jako aplikace do počítače i mobilu.
- Funguje i bez internetu.
- Všechna data zůstávají jen ve tvém zařízení. Nikam se neposílají, proto si občas stáhni zálohu (Nastavení → Data).

Soubory v tomto repozitáři generuje skript `build-web.py` ze zdrojové stránky `penizky.html`.
